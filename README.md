# farmanmial

Módulo personalizado para Odoo 19.0 que adapta reportes de inventario de Farm animals.

## Funcionalidad

- Agrega el total de producto en reportes de picking y entrega.
- Agrega código interno y código de barras en el albarán de entrega.
- Agrega lote/serie y fecha de expiración en líneas de entrega cuando aplica.
